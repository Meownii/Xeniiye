# Shop site template

All store copy is intentionally left as short placeholders. Replace each label in index.html and the page content templates in script.js with approved shop details.

## Profile image

Replace the text inside .phone-screen in index.html with an img element using the chosen image. The image is contained within the phone display using object-fit: cover.

## Navigation artwork

The seven navigation buttons use the supplied illustrations in assets/nav-*.webp. Replace an individual file to change its button artwork; the button states and bevels stay in style.css.

## Intro

The intro opens with the site, advances through placeholder dialogue with CLICK TO CONTINUE, can be skipped, and can be replayed from the content window title bar.

## Music

Add the real MP3 at assets/music.mp3. The compact player enables its controls only when the audio can be loaded. Replace MUSIC TITLE and ARTIST NAME in index.html. Playback starts only after Play is pressed and continues when the visitor changes pages.
